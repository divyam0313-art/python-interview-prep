# Python Interview Prep

32 coding problems for a 10+ year Python developer interview, ordered from easy to hard.
Each problem lives in its own folder:

- `question.md` - the problem, signature, examples and target efficiency
- `solution.py` - the concept explanation (module docstring) plus tested code

Try to solve the problem yourself before opening `solution.py`.
